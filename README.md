# 八字排盤

繁體中文八字排盤器。手機優先、完全離線運作、可加到主畫面當 App 用。

**https://u1tr4man.github.io/bazi/**

---

## 能做什麼

- 用西曆生日排盤，或反過來由四柱干支**反查**出生日期
- 四柱、藏干、十神、日主
- 大運按精確交運日分界，題頭同時列出起運流年
- 交運年點開會分段顯示交運前後；交運日過後可並看「交前／參照」與「交後／生效」兩柱
- 研究未來交運年時，點選流月／流日會依所選日期即時切換；交運日當天起立即顯示雙運柱
- 流年／流月／流日，打開就自動定位到今天
- 流年柱正下方顯示**行年虛歲**
- 四柱可切「年→時」或「時→年」；流年可切橫排或全部大運的直排矩陣
- 晚子時（23:00–23:59）**兩派都支援**，自己選，盤面會標明用了哪一派

## 離線使用

裝一次，之後開飛航模式也能排盤。三十秒，步驟見 **[離線使用說明.md](離線使用說明.md)**。

不想裝也可以：整個工具就是一個 `index.html`，存下來用瀏覽器打開一樣能用，永遠不需要網路。

## 隱私

所有計算都在你自己的裝置上完成。

**不上傳、也不儲存**出生日期、出生時間、性別或排盤結果。`localStorage` 裡只有三個顯示偏好：四柱排列、流年排列、晚子時口徑。沒有帳戶、沒有雲端同步、沒有分析追蹤。

## 排盤口徑（引擎 v2.1）

命理各派做法不同，所以這裡把採用的規則寫死並公開，讓你自己判斷合不合用。完整版見 **[CALENDAR_SPEC.md](CALENDAR_SPEC.md)**。

| 項目 | 採用的規則 |
|---|---|
| 時區 | 中國標準時間 UTC+8 鐘錶時間；不做真太陽時校正，不隨裝置所在地改變 |
| 年柱 | 以**立春交接時刻**換年（秒級），不以農曆正月初一 |
| 月柱 | 以二十四節氣的**「節」**換月，不以農曆初一；月干五虎遁 |
| 日柱 | JDN 純算術，錨點 2000-01-01＝戊午；**00:00 換日** |
| 晚子時 | 預設日柱算當日；可切換成算次日。**時柱兩派相同**（都以翌日日干起遁） |
| 時柱 | 23 時與 0 時皆為子；時干五鼠遁 |
| 起運 | 陽年男／陰年女順行，取下一個節；反之逆行取上一個節。3 日折 1 歲、1 日折 4 月、1 時折 5 日，分鐘參與換算 |
| 交運 | 出生日期依序加起運年／月／日，每步月底夾取；交運日 UTC+8 00:00 起屬新運，精度只到日 |
| 流年歸屬 | 每步固定十個流年、不重不漏；一年中途交運時標「交」，仍只顯示一次 |
| 行年虛歲 | 流年 − **年柱所屬干支年** + 1。立春前出生者年柱屬前一年，不用西曆出生年 |
| 支援範圍 | 1901-01-01 – 2100-12-31 |

節氣時刻為天文計算值，UTC+8，精確到秒，離線查表。年柱、月柱、起運、流年與流月共用同一份表。
完整九步、每步十個流年的 V2 範圍為 1901–2030 出生；2031 年後若後段大運超出已核節氣表，
頁面會明示而不會靜默少列。四柱排盤本身仍支援至 2100 年。

已與**香港天文台**《公曆與農曆日期對照表》交叉核對 11 個年份、132 個節：**131 相符、1 個歧異**。

相符的包含天文台自己標注為高風險的 2083 年立春（本表 23:58:22，距午夜僅 98 秒）。
歧異的是 **1917 大雪**——本表 12-08 00:00:59、天文台 12-07，兩套星曆差不到一分鐘卻剛好跨過日界。
影響只有 1917-12-07 深夜那一小時出生的人，月柱會與天文台口徑差一個月。詳見 CALENDAR_SPEC.md。

## 這個資料夾是什麼（維護者看的）

`index.html` 是母專案 `tools/build_paipan.py` 產生的**單檔產物**，字型與圖示都已內嵌。
本 README 與 `離線使用說明.md`、`CALENDAR_SPEC.md` 也由 build 同步過來。

**不要直接改這裡的任何檔案**——下次 build 會全部覆蓋。要改請動母專案：

| 這裡的檔案 | 改哪裡 |
|---|---|
| `index.html` | `tools/paipan_src.html` |
| `sw.js`、`manifest.webmanifest` | `pwa/` |
| `README.md` | `pwa/README.md` |
| `icons/*` | `tools/make_paipan_icons.py` |
| 曆法與大運 | `lib/calendar.js`、`lib/solar_terms.js`、`lib/dayun.js` |

改完跑 `python3 tools/build_paipan.py`，再把這個資料夾 push 上去。

### 更新 PWA 版本

改了任何會進快取的檔案，記得同步提升 `pwa/sw.js` 裡的 `CACHE` 版本號，否則使用者不會收到更新提示。

### 部署

這個資料夾是**獨立的公開 repo**，不要併進母專案發佈——母專案含微信群命例、名人研究資料與書籍逐字稿，一旦公開全部外洩。

到 repo 的 Settings → Pages → Source 選 `main` 分支根目錄即可。
